C++ Function Types

A function is a named block of code that does one job. main() calls it, the function runs, and then control returns to the statement after the call. Functions are grouped o four types by two questions: does it receive data (parameters), and does it send a value back (return)?

Parts of a function

int add(int a, int b) // function header
{
int sum = a + b; // function body
return sum; // sends ONE value back
}
total = add(x, y); // function call in main()
return type: the type of the value sent back, or void for none function name parameter list: the data it receives return statement
Parameter

A variable in the function header, e.g. a and b. It receives a value when the function is called.

Argument

The value passed in the call, e.g. x and y. Arguments are matched to parameters by position.

Definition

The header plus the body in { }: the code that actually runs.

Function prototypes

The compiler reads a program from top to bottom. When main() calls a function, the compiler must already know that function's name, return type and parameters. A prototype is a declaration that gives this information before main(), so the full definition can be written after main().

Prototype = header + semicolon

int add(int a, int b);  // with names
int add(int, int);      // names optional
  • It ends with ; and has no body.
  • It must match the definition: same return type, name, and number, order and types of parameters.
  • Place it after using namespace std; and before main().
  • A prototype does not run. The program still starts in main().

Layout with prototypes (used on this page)

#include <iostream>
using namespace std;

int add(int, int);         // 1. prototype

int main()                // 2. main() calls it
{
    cout << add(4, 5);
    return 0;
}

int add(int a, int b)     // 3. definition
{
    return a + b;
}

What goes wrong without it

No prototype, definition after main()error: 'add' was not declared in this scope
Prototype does not match the definitionundefined reference to `add(int, int)'

The other correct layout is to write the whole definition above main(); then no prototype is needed. Prototypes are preferred because main() comes first and reads like a summary of the program.

A function returns only one value

  • return sends back exactly one value, of the function's return type, to the place where the function was called.
  • return also ends the function immediately. Any statement after it is never run.
  • A void function returns no value. It may use return; on its own to end early, or simply reach the closing }.
  • The returned value must be used by the caller: store it (total = add(x, y);), display it (cout << add(x, y);), or use it in an expression.
  • Need two results, such as a total and an average? Write two functions, or call one function twice.
// Mistake 1: trying to return two values
int f()
{
    int a = 3, b = 7;
    return a, b;   // returns only 7
}

// Mistake 2: two return statements
int g()
{
    return 1;      // function ends here
    return 2;      // never runs
}

cout << f() << " " << g(); displays 7 1. In return a, b; the comma operator throws away a, and the compiler only warns you.

    The problem

    A lecturer wants a program that reads a student's marks for three tests, calculates the average, and displays it with 2 decimal places together with PASS (average 50 or above) or FAIL.

    The job is split into four small functions, one of each type, so main() only has to call them in order.

    FunctionTypeJob
    void showTitle()1Display the report title. Needs nothing, returns nothing.
    int readMark()2Read one mark and return it. Called 3 times.
    double average(int a, int b, int c)3Receive 3 marks, return their average: three values in, one value out.
    void showResult(double avg)4Receive the average and display it with PASS or FAIL.
